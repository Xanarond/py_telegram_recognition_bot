# Функционал пересказа и озвучивания

## 🆕 Новые возможности

Добавлены два новых агента для расширения функциональности телеграм-бота:

### 📄 Агент пересказа (`SummaryAgent`)
- **Краткий пересказ** - сжатая суть статьи в нескольких предложениях
- **Подробный пересказ** - структурированное изложение по разделам
- **Анализ качества** - оценка эффективности пересказа

### 🎵 Агент озвучивания (`TTSGenerator`)
- **Text-to-Speech** - преобразование пересказа в аудио
- **Поддержка нескольких движков** - Google TTS и pyttsx3
- **Автоочистка** - удаление старых аудиофайлов

## 🔧 Установка зависимостей

Добавлены новые зависимости в `requirements.txt`:
```bash
gTTS==2.4.0      # Google Text-to-Speech
pyttsx3==2.90    # Локальный TTS движок
```

Установка:
```bash
pip install gTTS==2.4.0 pyttsx3==2.90
```

## ⚙️ Конфигурация

Новые настройки в `config.py`:

```python
# Настройки пересказа и TTS
ENABLE_SUMMARY_AGENT = True  # Включить агент пересказа
ENABLE_TTS_AGENT = True      # Включить text-to-speech агент

# Настройки TTS
TTS_DEFAULT_LANGUAGE = 'ru'
TTS_DEFAULT_ENGINE = 'gtts'  # 'gtts' или 'pyttsx3'
TTS_MAX_TEXT_LENGTH = 25000   # Максимальная длина текста для озвучивания
TTS_CLEANUP_HOURS = 24       # Через сколько часов удалять временные аудиофайлы
```

## 🔄 Workflow

1. **Пользователь отправляет ссылку**
2. **Система анализирует контент** (существующий функционал)
3. **Пользователь запрашивает пересказ**
4. **`SummaryAgent` создает пересказ** с помощью Claude 3.5 Sonnet
5. **Система отображает пересказ** с красивым форматированием
6. **Пользователь может озвучить пересказ**
7. **`TTSGenerator` создает аудио** с помощью Google TTS или pyttsx3
8. **Аудиофайл отправляется пользователю**

## 🛠️ TTS движки

### Google TTS (gTTS)
- **Преимущества**: высокое качество звука, поддержка множества языков
- **Требования**: интернет-соединение
- **Формат**: MP3

### pyttsx3 (локальный)
- **Преимущества**: работает без интернета, быстрый
- **Недостатки**: качество зависит от системы
- **Формат**: WAV

## Недавние исправления

### Исправление ошибки ObjectId (Декабрь 2025)

**Проблема:** При нажатии на кнопку "🎵 Озвучить пересказ" пользователи сталкивались с ошибкой:
```
'85dcd913d7137406f98db59' is not a valid ObjectId, it must be a 12-byte input or a 24-character hex string
```

**Причина:** Telegram ограничивает `callback_data` до 64 байтов, что может приводить к обрезанию ObjectId MongoDB (23 символа вместо 24).

**Исправления:**
1. ✅ Добавлена валидация ObjectId во всех функциях MongoDB
2. ✅ Улучшена обработка ошибок с информативными сообщениями
3. ✅ Добавлено логирование для отладки проблем с ID
4. ✅ Пользователям предоставляется четкая навигация при возникновении ошибки

**Дополнительная защита:**
- Все функции MongoDB теперь проверяют валидность ObjectId перед обращением к базе
- При обнаружении обрезанного ID (23 символа) пользователь получает специальное сообщение
- Логирование помогает выявлять проблемы с передачей ID в callback данных
