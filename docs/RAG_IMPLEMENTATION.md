# Реализация RAG и векторной базы данных

## 📋 Обзор

Проект расширен функциональностью RAG (Retrieval-Augmented Generation) и векторной базы данных для создания интеллектуальной системы управления знаниями.

### Новые модули

#### 1. **storage/vector_manager.py**
Менеджер векторной базы данных Chroma DB
- Хранение эмбеддингов контента
- Семантический поиск
- CRUD операции с векторами

#### 2. **analyzers/embedding_generator.py**
Генератор эмбеддингов
- Поддержка OpenAI, Sentence-Transformers, Cohere
- Многоязычная модель `intfloat/multilingual-e5-large`
- Пакетная обработка

#### 3. **analyzers/vectorization_service.py**
Сервис векторизации
- Автоматическая векторизация при сохранении
- Поиск похожих документов
- Рекомендательная система

#### 4. **analyzers/rag_agent.py**
RAG агент для ответов на вопросы
- Контекстная генерация ответов
- Цитирование источников
- Сравнительный анализ
- Синтез информации

#### 5. **analyzers/content_analytics.py**
Аналитика контента
- Анализ интересов пользователя
- Выявление трендов
- Кластеризация контента
- Рекомендации

#### 6. **handlers/rag_handlers.py**
Обработчики RAG команд
- `/search` - семантический поиск
- `/ask` - вопросы к базе знаний
- `/compare` - сравнение источников
- `/synthesize` - синтез информации
- `/similar` - похожие статьи

#### 7. **handlers/analytics_handlers.py**
Обработчики аналитики
- `/analytics` - аналитика интересов
- `/trends` - трендовые темы
- `/clusters` - кластеризация

## 🚀 Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

Новые зависимости:
- `chromadb==0.4.22` - векторная база данных
- `sentence-transformers==2.3.1` - локальные эмбеддинги
- `openai==1.12.0` - OpenAI API (опционально)
- `cohere==4.47` - Cohere API (опционально)

### 2. Конфигурация

В `config.py` добавлены настройки:

```python
# RAG и векторная БД
ENABLE_RAG = True
ENABLE_VECTOR_DB = True
VECTOR_DB_PATH = "data/chroma_db"

# Эмбеддинги
EMBEDDING_PROVIDER = "sentence-transformers"
EMBEDDING_MODEL = "intfloat/multilingual-e5-large"

# Семантический поиск
SEMANTIC_SEARCH_TOP_K = 10
SEMANTIC_SEARCH_MIN_SCORE = 0.5

# RAG параметры
RAG_CONTEXT_SOURCES = 5
RAG_MAX_CONTEXT_LENGTH = 8000
RAG_TEMPERATURE = 0.3
```

### 3. Первый запуск

При первом запуске:
1. Автоматически создается директория `data/chroma_db`
2. Инициализируется векторная база данных
3. Загружается модель эмбеддингов (может занять время)

## 📖 Использование

### Семантический поиск

```
/search машинное обучение
```

Находит статьи по смыслу, а не только по точным словам.

### Вопросы к базе знаний

```

```

```

Сравнивает разные материалы по теме, выявляет общее и различия.

### Синтез информации

```

```

Создает обзор по теме на основе всех релевантных статей.

### Похожие статьи

```

```

Находит похожие материалы на основе семантического сходства.

### Аналитика

```

Группирует ваш контент по тематическим кластерам.

## 🔧 Технические детали

### Векторизация контента

При сохранении новой статьи:

1. **Извлечение контента** - получение текста из HTML
2. **Подготовка текста** - объединение заголовка, резюме, тегов и контента
3. **Генерация эмбеддинга** - создание векторного представления
4. **Сохранение в Chroma DB** - индексирование для быстрого поиска

### RAG пайплайн

При запросе пользователя:

1. **Векторизация запроса** - преобразование вопроса в вектор
2. **Семантический поиск** - поиск похожих документов в Chroma DB
3. **Получение контекста** - извлечение полного текста из MongoDB
4. **Генерация ответа** - Claude анализирует контекст и отвечает
5. **Форматирование** - красивое отображение с источниками

### Модель эмбеддингов

По умолчанию используется `intfloat/multilingual-e5-large`:
- **Размерность**: 1024
- **Языки**: русский, английский и др.
- **Качество**: высокое для семантического поиска
- **Размер**: ~2 ГБ

Альтернативы:
- **OpenAI text-embedding-3-small** - через API, высокое качество
- **Cohere embed-multilingual-v3.0** - через API, оптимизирован для поиска

### Производительность

- **Векторизация**: ~1-2 сек на статью
- **Поиск**: ~100-200 мс для 1000 документов
- **RAG ответ**: ~3-5 сек (зависит от Claude API)

## 🐛 Troubleshooting

### Проблема: Модель не загружается

**Решение**: Проверьте интернет-соединение и свободное место (минимум 3 ГБ).

### Проблема: Медленный поиск

**Решение**: Убедитесь, что векторная БД проиндексирована. При большом количестве документов (>10K) рассмотрите использование Qdrant.

### Проблема: RAG не работает

**Решение**: Проверьте `ENABLE_RAG = True` в config.py и наличие ANTHROPIC_API_KEY.

### Проблема: Ошибки памяти

**Решение**: Используйте меньшую модель эмбеддингов или переключитесь на API-based решение (OpenAI/Cohere).
