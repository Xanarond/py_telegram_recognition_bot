# 🚀 Быстрый старт с RAG функциональностью

## Что нового?

Ваш Telegram-бот теперь имеет:
- 🔍 **Семантический поиск** - находите статьи по смыслу
- 💬 **Чат с базой знаний** - задавайте вопросы своим статьям
- 📊 **Аналитика интересов** - узнайте свои тренды и паттерны
- 🤖 **RAG ответы** - получайте ответы с цитированием источников

## Установка (5 минут)

### 1. Обновите зависимости

```bash
pip install -r requirements.txt
```

Это установит:
- `chromadb` - векторная база данных
- `sentence-transformers` - модель для эмбеддингов
- `openai`, `cohere` - опциональные провайдеры

### 2. Запустите бота

```bash
python main.py
```

При первом запуске:
- Загрузится модель эмбеддингов (~2 ГБ, займет 5-10 минут)
- Создастся директория `data/chroma_db`
- Векторная БД будет готова к работе

### 3. Начните использовать

Все существующие статьи автоматически векторизуются при следующем анализе.

## Новые команды

### Семантический поиск
```
/search машинное обучение
```
Найдет все статьи по теме, даже если точных слов нет в тексте.

### Вопросы к базе
```
/ask Что говорят статьи о микросервисах?
```
Получите ответ на основе ваших материалов с указанием источников.

### Сравнение
```
/compare Python vs JavaScript
```
Сравните разные подходы на основе ваших статей.

### Синтез
```
/synthesize искусственный интеллект
```
Создайте обзор по теме из всех релевантных материалов.

### Похожие статьи
```
/similar <ID статьи>
```
Найдите похожие материалы.

### Аналитика
```
/analytics - ваши интересы и статистика
/trends 30 - тренды за 30 дней
/clusters - группировка по темам
```

### Справка
```
/rag_help - подробная справка по RAG
```

## Конфигурация (опционально)

В `config.py` можно настроить:

```python
# Отключить RAG (если не нужен)
ENABLE_RAG = False
ENABLE_VECTOR_DB = False

# Изменить провайдера эмбеддингов
EMBEDDING_PROVIDER = "openai"  # или "cohere", "sentence-transformers"
OPENAI_API_KEY = "your-key"

# Настроить параметры поиска
SEMANTIC_SEARCH_TOP_K = 10  # количество результатов
RAG_CONTEXT_SOURCES = 5     # источников для RAG ответа
```

## Как это работает?

1. **При сохранении статьи:**
   - Текст векторизуется (превращается в числовой вектор)
   - Вектор сохраняется в Chroma DB
   - Метаданные остаются в MongoDB

2. **При поиске:**
   - Ваш запрос векторизуется
   - Находятся похожие векторы (= похожие статьи)
   - Результаты ранжируются по релевантности

3. **При RAG запросе:**
   - Находятся релевантные статьи
   - Их содержимое передается Claude
   - Claude генерирует ответ на основе контекста
   - Указываются источники информации

## Отключение RAG (если нужно)

Если RAG не нужен или возникают проблемы:

```python
# В config.py
ENABLE_RAG = False
ENABLE_VECTOR_DB = False
```

Бот продолжит работать в обычном режиме.

## Troubleshooting

### Долго загружается при первом запуске
✅ Нормально! Загружается модель эмбеддингов (~2 ГБ).

### Ошибка памяти
💡 Используйте API-based эмбеддинги (OpenAI/Cohere) вместо локальных.

### RAG не отвечает
🔍 Проверьте:
- `ENABLE_RAG = True` в config.py
- Наличие `ANTHROPIC_API_KEY`
- Логи в `logs/bot.log`
