# ⭐ Быстрый старт: Рейтинг статей

## Запуск миграции

Если у вас уже есть существующие статьи в базе данных, запустите скрипт миграции:

```bash
cd /opt/projects/telegram_bot_analytic
python scripts/add_rating_field.py
```

Скрипт автоматически:
- Добавит поле `rating` (значение 0) ко всем существующим синопсисам
- Создаст необходимые индексы для оптимизации
- Выведет статистику по рейтингам

## Использование в боте

### 1. Просмотр статьи с рейтингом

```
/sources → Выберите статью → Нажмите 📋 [Название]
```

Вы увидите:
- Текущий рейтинг статьи
- Кнопки для установки рейтинга (⭐ 1-5)
- Кнопку сброса рейтинга (🔄 Сброс)

### 2. Установка рейтинга

**Вариант 1: Через детальный просмотр**
1. Откройте статью через `/sources`
2. Нажмите на кнопку с нужным количеством звезд:
   - `⭐ 1` - плохая статья
   - `⭐⭐ 2` - ниже среднего
   - `⭐⭐⭐ 3` - нормальная
   - `⭐⭐⭐⭐ 4` - хорошая
   - `⭐⭐⭐⭐⭐ 5` - отличная
3. Рейтинг сохранится автоматически

**Вариант 2: Сброс рейтинга**
- Нажмите кнопку `🔄 Сброс` для удаления оценки

### 3. Просмотр статистики

```
/stats
```

В разделе **⭐ Рейтинги** вы увидите:
```
⭐ Рейтинги:
• Оценено статей: 15 из 50
• ⭐⭐⭐⭐⭐: 5
• ⭐⭐⭐⭐: 7
• ⭐⭐⭐: 2
• ⭐⭐: 1
• ⭐: 0
```

### 4. Рейтинг в списке источников

Рейтинг автоматически отображается в списке источников:

```
📖 📄 Интересная статья о Python
   📊 8.5/10 • 🟡 MEDIUM • ⏱️ 5 мин • ⭐⭐⭐⭐⭐ (5/5)
   📅 10.10.2025 • 🏷️ `python` `programming`
```

## Интеграция с существующими функциями

### Совместимость

✅ **Полностью совместимо с:**
- Статусом прочтения (✅/📖)
- Пересказами (📄/📚)
- Озвучиванием (🎵/🎙️)
- Экспортом в PDF
- Фильтрацией источников

### Примеры использования

**Workflow 1: Оценка прочитанного**
```
1. Читаете статью
2. Отмечаете как прочитанную ✅
3. Ставите рейтинг ⭐⭐⭐⭐⭐
```

**Workflow 2: Быстрая оценка**
```
1. Анализируете ссылку
2. Сразу ставите рейтинг
3. Возвращаетесь к чтению позже
```

**Workflow 3: Пересмотр оценок**
```
1. /sources → Выбираете статью
2. Меняете рейтинг на более подходящий
3. Или сбрасываете рейтинг кнопкой 🔄
```

## Советы по использованию

### Система оценок

Рекомендуемая шкала:
- ⭐ **1 звезда** - Бесполезная или некачественная статья
- ⭐⭐ **2 звезды** - Слабая статья, мало полезного
- ⭐⭐⭐ **3 звезды** - Нормальная статья, есть полезная информация
- ⭐⭐⭐⭐ **4 звезды** - Хорошая статья, много ценной информации
- ⭐⭐⭐⭐⭐ **5 звезд** - Отличная статья, очень полезная

### Когда ставить рейтинг

**Лучшее время:**
- После прочтения статьи (наиболее точная оценка)
- При сохранении особо ценных материалов
- При формировании личной базы знаний

**Можно пропустить:**
- Новости и актуальные события
- Статьи "на потом"
- Технические справочники

## Устранение неполадок

### Рейтинг не обновляется

**Причина:** Проблема с подключением к базе данных

**Решение:**
```bash
# Проверьте статус MongoDB
docker ps | grep mongo

# Перезапустите контейнер если нужно
docker-compose restart mongodb
```

### Статистика не показывает рейтинги

**Причина:** Не запущена миграция

**Решение:**
```bash
python scripts/add_rating_field.py
```

### Кнопки рейтинга не появляются

**Причина:** Старая версия кода

**Решение:**
```bash
# Перезапустите бота
docker-compose restart telegram_bot
```
